🌐 Kah.Dev

Site pessoal/portfólio para apresentação de serviços de desenvolvimento web, com foco em pequenos negócios e criadores de conteúdo.

🎯 Objetivo

Apresentar serviços, projetos, processo de desenvolvimento e canais de contato de forma simples, visual e responsiva.

🧩 Estrutura

🏠 Hero — apresentação principal e chamadas para ação.

🛠️ Serviços — site institucional, landing page e link na bio.

💼 Portfólio — projetos gerados dinamicamente pelo JavaScript.

🔄 Processo — etapas do primeiro contato até a publicação.

📲 Contato — Instagram e WhatsApp.

🔗 Footer — navegação e ano atualizado automaticamente.

🛠️ Tecnologias

🧱 HTML5

🎨 CSS3

⚡ JavaScript

🔤 Google Fonts: Fraunces, Space Grotesk e Space Mono

📁 Estrutura de arquivos

/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js

⚙️ Funcionalidades

📱 Layout responsivo.

🧭 Navegação superior e lateral por pontos.

🍔 Menu mobile controlado por JavaScript.

🖥️ Mockup de navegador no Hero.

🎞️ Marquee horizontal com serviços.

💼 Portfólio gerado pelo array PROJECTS.

👁️ Scroll Spy com IntersectionObserver.

📅 Ano do rodapé atualizado automaticamente.

✨ Animações e efeitos de hover.

♿ Suporte à preferência de redução de movimento.

💼 Serviços

01 — Site institucional

Página para apresentar negócio, serviços, informações e contatos.

02 — Landing page

Página focada em venda, lançamento ou captação de contatos.

03 — Link na bio

Mini-site personalizado para reunir links e apresentar a identidade do profissional.


Cada projeto possui título, categoria, descrição e endereço exibido no mockup.

🎨 Identidade visual

🖤 Preto e carvão para seções escuras.

🤍 Off-white para seções claras.

🟠 Laranja como cor de destaque.

✨ Glow e efeitos visuais.

📰 Fraunces para títulos.

🔤 Space Grotesk para textos.

💻 Space Mono para elementos técnicos.

📱 Responsividade

Em telas menores, o layout adapta o Hero, serviços e portfólio para uma coluna, ativa o menu mobile e oculta a navegação lateral.

🧠 JavaScript

O script.js é responsável por gerar os cards do portfólio, controlar o menu mobile, atualizar o ano do rodapé e destacar a seção atual durante o scroll.

🚀 Como executar

Abra index.html em um navegador. Para desenvolvimento, recomenda-se utilizar o Live Server no VS Code.

✏️ Personalização

📝 Textos: index.html

💼 Projetos: js/script.js

🎨 Estilos: css/style.css

🔗 Instagram e WhatsApp: substituir pelos links reais

🖼️ Imagens e recursos: adicionar conforme a identidade do projeto

📌 Observação

Os dados e links presentes no projeto devem ser substituídos pelas informações reais antes da publicação.

👨‍💻 Desenvolvimento

Projeto criado como vitrine para serviços de criação de sites personalizados, com foco em uma apresentação profissional, simples e responsiva.
